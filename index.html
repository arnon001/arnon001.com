About

How I got here

I'm Arnon, 19, from Israel. I got into coding by accident — around 10 I built my first game in Java, mostly because I wanted to make the things I was playing. That turned into a habit I never dropped.

I'm self-taught, which means I learn by shipping: pick something I care about, break it, read the source, rebuild it. I love PC games, and a lot of my work starts as "this should exist again".

Right now that means TypeScript and Node on the backend, Linux on a server I run myself, and a lot of AI-assisted coding to move faster than I could alone.

Projects

Things I rebuilt

01 In progress 2025 — now

Ekoloko Rewritten

I help rebuild the server side of Ekoloko so the game can return after more than five years offline.

The original client survived in web archives; the backend did not. So we reconstruct it — packet by packet, room by room — vibe coded in ActionScript and driven by a lot of guesswork, old screenshots and packet captures. The goal is a playable hub world again, not a museum piece.

  • ActionScript 3
  • Node.js

02 Shipped 2025

Flight Arcade

A mobile arcade game collection — a Ball Blast-style shooter, a Subway Surfers-style runner and a set of mini games — shipped as an Android APK.

Built as one collection instead of three separate apps: shared menus, shared progression, one install. The shooter is about numbered blocks and a cannon that never stops upgrading; the runner is three lanes and reflexes. Small sessions, instant restart, no waiting around.
